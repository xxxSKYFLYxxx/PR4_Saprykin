# Контрольные вопросы (Практическая работа 4: автозагрузка, абстрактные классы, свойства)

1. **Какой момент времени выбирает PHP для вызова автозагрузчика и что произойдёт, если файл класса так и не найден?**
   PHP вызывает зарегистрированные автозагрузчики лениво — в момент первого обращения в коде к ещё не загруженному классу, интерфейсу или трейту (например, при `new ClassName()`, наследовании или вызове статического метода). Если ни один автозагрузчик не смог подключить нужный файл, PHP выбросит фатальную ошибку `Error: Class "..." not found`.

2. **В чём преимущество `spl_autoload_register()` перед удалённой функцией `__autoload()`?**
   Функция `__autoload()` позволяла объявить только один глобальный загрузчик на весь проект, из-за чего сторонние библиотеки конфликтовали между собой. `spl_autoload_register()` позволяет зарегистрировать очередь из нескольких независимых функций-загрузчиков, которые вызываются по порядку, пока класс не будет найден.

3. **Чем абстрактный класс отличается от интерфейса? Когда что выбрать?**
   - **Абстрактный класс** может содержать как абстрактные методы без тела, так и обычные методы с реализацией, свойства и константы. Наследоваться можно только от одного абстрактного класса (`extends`). Его выбирают, когда нужно объединить общую логику и состояние родственных сущностей.
   - **Интерфейс** задаёт только публичный контракт (сигнатуры методов и константы) без хранения состояния, но класс может реализовать сразу несколько интерфейсов (`implements`). Его выбирают для описания общего поведения несвязанных между собой классов.

4. **Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?**
   - Создать объект абстрактного класса через `new` **нельзя** — PHP выдаст фатальную ошибку `Cannot instantiate abstract class`.
   - Объявить абстрактное свойство в PHP **нельзя** — модификатор `abstract` применяется только к классам и методам (обязательность наличия свойства у наследников задаётся через конструктор абстрактного класса или абстрактные геттеры).

5. **Чем `static`-свойство отличается от обычного? Как обратиться к нему внутри и вне класса?**
   Обычное свойство принадлежит конкретному объекту и хранит его индивидуальные данные, а статическое (`static`) принадлежит самому классу и является общим для всех его экземпляров.
   - Внутри класса: `self::$property` (или `static::$property`).
   - Вне класса: `ClassName::$property` (если свойство `public`).

6. **Что делает модификатор `readonly` и какие ограничения он накладывает?**
   Модификатор `readonly` (PHP 8.1+) запрещает изменять значение свойства после его первичной инициализации. Ограничения:
   - присвоить значение можно только один раз и только из области видимости того класса, где свойство объявлено (обычно в конструкторе);
   - свойство обязательно должно иметь тип и не может иметь значения по умолчанию;
   - `readonly` нельзя применять к `static`-свойствам.
